# Arquitectura de componentes

## 6. ARQUITECTURA FRONTEND

Respetar el framework existente.

No migrar automáticamente un proyecto a React, Next.js, Vue u otra tecnología.

Si el proyecto es nuevo, Claude deberá evaluar las alternativas y justificar su elección.

La arquitectura deberá separar:

- Componentes primitivos.
- Componentes compuestos.
- Layouts.
- Páginas o rutas.
- Estilos.
- Tokens.
- Hooks o composables.
- Estado de interfaz.
- Utilidades de presentación.
- Assets.
- Pruebas.

Aplicar:

- Responsabilidad única.
- Reutilización.
- Bajo acoplamiento.
- Tipado cuando corresponda.
- Nombres consistentes.
- Separación entre presentación y lógica.
- Componentes accesibles.
- Evitar duplicación.
- Documentación de contratos.

No modificar backend, bases de datos, autenticación de servidor ni infraestructura fuera del alcance aprobado.
