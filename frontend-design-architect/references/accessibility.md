# Accesibilidad

### 5.4 Accesibilidad

Utilizar WCAG 2.2 AA como referencia de aceptación.

Incluir:

- HTML semántico.
- Navegación por teclado.
- Foco visible.
- Contraste suficiente.
- Etiquetas accesibles.
- Mensajes de error comprensibles.
- Compatibilidad con lectores de pantalla.
- Soporte de zoom y reflow.
- Objetivos táctiles adecuados.
- Preferencias de movimiento reducido.

No depender únicamente de herramientas automáticas: realizar también comprobaciones manuales.

## Registro de verificación

Documentar ruta, componente, criterio WCAG, método automático o manual, resultado, evidencia, severidad y corrección. Distinguir comprobaciones pendientes de las ejecutadas; una herramienta automática no acredita por sí sola conformidad WCAG.
